### 2.2 Feature Engineering (Step 2)
Derived 8 features from raw data:
  1. fuel_cost_index = annual_driving_km / 100 * fuel_consumption_combined_l_100km * 1.5
  2. emission_intensity = co2_emissions_g_km / (engine_power_hp + 1)
  3. efficiency_ratio = engine_efficiency_score / (engine_displacement_cc + 1)
  4. feature_density = total_feature_count / (length_mm + 1)
  5. performance_density = engine_power_hp / (curb_weight_kg + 1)
  6. co2_per_km = co2_emissions_g_km / (annual_driving_km + 1) * 1000
  7. green_score_ratio = environmental_score / (co2_emissions_g_km + 1)
  8. acceleration_per_power = zero_to_100_kmh_seconds / (engine_power_hp + 1)
- Original columns: 31
- After feature engineering: 39 columns
